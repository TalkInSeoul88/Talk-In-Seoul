# 음절(syllables) recording checklist

Jung: record the **140 basic CV blocks** in this order (ㄱ row through ㅎ row). One Hangul per MP3. Drop each file into this folder (`public/audio/`) using the exact filename. Do **not** rename after recording — the app looks up `syllable-{roman}.mp3`.

**All 10 vowel rows are in (140/140):** ㅏㅑㅓㅕㅗㅛㅜㅠㅡㅣ. 티 is `syllable-ti.mp3`.

All 140 MP3s are in this folder. If a file is ever missing, students see **Audio coming soon** and Play stays disabled. Existing `vowel-*.mp3` files must stay as they are.

## How to drop files in

1. Record on the same phone/mic you used for the 모음(vowels) clips, if you can.
2. Say the syllable once, clearly, with a little silence at each end.
3. Export as MP3.
4. Name it exactly as in the **File** column (lowercase, including the `syllable-` prefix).
5. Put the file in `public/audio/` (this folder).
6. Commit and push — or send the files to whoever deploys. After Vercel deploys, Play lights up. No code change.

## Filename rule

`syllable-{roman}.mp3` using Revised Romanization.

- Initial 자음(consonants): ㄱ g, ㄴ n, ㄷ d, ㄹ r, ㅁ m, ㅂ b, ㅅ s, ㅇ *(silent)*, ㅈ j, ㅊ ch, ㅋ k, ㅌ t, ㅍ p, ㅎ h
- 모음(vowels): ㅏ a, ㅑ ya, ㅓ eo, ㅕ yeo, ㅗ o, ㅛ yo, ㅜ u, ㅠ yu, ㅡ eu, ㅣ i
- ㅇ is silent: 아 → `syllable-a.mp3` (this is **not** `vowel-a.mp3`, which is the letter ㅏ)
- 가 → `syllable-ga.mp3`

Full romanization map: [README.md](./README.md) in this folder.
